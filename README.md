MHA.NET

پنل مدیریت سرویس‌های VPN بر پایه VLESS و Xray

معرفی پروژه

MHA.NET یک پنل مدیریتی برای ساخت و مدیریت کاربران، اشتراک‌ها، کانفیگ‌ها و سرورها است.

امکانات پنل

- داشبورد مدیریت و نمایش آمار
- مدیریت کاربران
- ساخت و مدیریت اشتراک‌ها
- ساخت، ویرایش و حذف کانفیگ‌های VLESS
- مدیریت سرورها
- نمایش حجم مصرفی و تاریخ انقضا
- مدیریت لینک‌های اشتراک
- تنظیمات امنیتی و حساب مدیر
- پشتیبانی تلگرام

فناوری‌ها

- HTML
- CSS
- JavaScript
- Cloudflare Workers
- Cloudflare D1
- Xray / VLESS
